# 🐂 TypingBull

> Master touch typing with gamified practice, 3D visual environments, and interactive arcade games.

**TypingBull** is a modern, interactive touch-typing platform engineered to make typing fluency engaging, intuitive, and fun. It combines structured pedagogical lessons, arcade-style typing mini-games, real-time WPM/accuracy feedback, and an AI tutor companion (**BullBot**).

---

## ✨ Features

- 🎯 **Structured Curriculum**: Progressive lessons covering home row fundamentals, upper & bottom rows, numbers, symbols, and custom text drills.
- 🎮 **Arcade Mini-Games**:
  - **Lilypad Leap**: Hop across lilypads by typing target words accurately before time runs out.
  - **Neon Velocity**: Fast-paced arcade typing challenges with Phaser-powered dynamics.
- 🤖 **BullBot AI Tutor**: Real-time floating companion providing pacing tips, error diagnosis, and encouragement.
- 🌌 **Living 3D Environment**: Dynamic Three.js ambient visual background and responsive audio feedback (Howler.js).
- 📊 **Real-Time Analytics**: Live tracking of Words Per Minute (WPM), raw WPM, accuracy %, streak counters, and keystroke errors.
- 🌓 **Themes & Visual Polish**: Fluid dark/light mode switching styled with Tailwind CSS and Framer Motion micro-interactions.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling & Animation**: Tailwind CSS v4, Framer Motion, GSAP
- **Games & 3D**: Three.js, Phaser
- **Audio**: Howler.js
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/RishabhDev817/TypingBull.git

# Navigate to project directory
cd TypingBull

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to start typing!
